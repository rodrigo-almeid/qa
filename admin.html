⚠️ Regras do Firestore recomendadas

Aplique estas regras no console Firebase → Firestore → Rules para proteger a escrita:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      // Usuário lê seus próprios dados; admin lê qualquer um
      allow read: if request.auth != null &&
        (request.auth.uid == userId ||
         request.auth.token.email == "almeidainteligencia@gmail.com");

      // Apenas o admin escreve
      allow write: if request.auth != null &&
        request.auth.token.email == "almeidainteligencia@gmail.com";
    }
  }
}
