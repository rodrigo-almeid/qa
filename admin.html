⚠️ Regras do Firestore necessárias para o painel funcionar

O painel usa autenticação anônima automática. Aplique estas regras no Firebase Console → Firestore → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Usuários: leitura/escrita requer autenticação (anônima ou real)
    match /users/{userId} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null;
    }

    // Empréstimos: cada usuário acessa só os seus; admin (autenticado) acessa todos
    match /loans/{userId}/loans/{loanId} {
      allow read, write: if request.auth != null &&
        request.auth.uid == userId;
    }
    // Permite que o painel leia/delete o documento pai do subcollection
    match /loans/{userId} {
      allow read, delete: if request.auth != null;
    }
  }
}

Ative também Anonymous Authentication no Firebase Console → Authentication → Sign-in method.
